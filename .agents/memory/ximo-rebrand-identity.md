---
name: Ximo branding and existing installs
description: Why the visible Ximo rebrand does not change the existing native app identity
---

Use Ximo for the app's visible name, logo, splash, and user-facing copy. Keep the existing native package/bundle identifiers unless the user specifically asks for a new install identity.

**Why:** Changing native identifiers would make a rebranded build install as a separate app rather than update the one users already have. A name, image, and copy change does not require that migration.

**How to apply:** Keep future UI and share copy branded Ximo, but treat any change to native identifiers or existing deep-link schemes as a separate compatibility decision.
