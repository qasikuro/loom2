# Profile companion Rive project

Build locally with the Rive CLI. Do not push this project to a Rive account.

- Read the relevant `rive docs` and `rive schema` output before changing markup.
- After every edit, run `node generate.mjs`, `rive . --verify`, and
  `rive inspect . --summary`.
- When appearance matters, capture `rive . --screenshot=build/preview.png
  --advance=1` and inspect the image.
- The profile photo is a separate, fixed native image. Keep its transparent
  aperture clear in every companion artboard.
